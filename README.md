# 💍 دعوة الزفاف الرقمية - Wedding Invitation

دعوة زفاف رقمية تفاعلية وأنيقة لحفل زفاف مصطفى وإيمان، تجمع بين التصميم الحديث والعناصر التقليدية العربية الكلاسيكية.

## ✨ المميزات الرئيسية

### 🎭 التصميم والواجهة
- **تصميم استجابي** - متوافق بشكل كامل مع جميع الأجهزة (الهاتف، التابلت، الحاسوب)
- **ألوان أنيقة** - نظام ألوان ذهبي وكريمي فاخر
- **خطوط عربية جميلة** - استخدام خطوط عربية احترافية (Amiri, Reem Kufi, Aref Ruqaa)
- **واجهة RTL** - دعم كامل لاتجاه النصوص من اليمين لليسار

### 🎪 العناصر التفاعلية

#### 1️⃣ المغلف مع الختم الشمعي
```
- تأثير بصري ذهبي فاخر
- عند ا��ضغط: توهج ضوئي أبيض جميل
- يفتح المحتوى تلقائياً بعد التأثير
```

#### 2️⃣ كروت كشف التاريخ
```
- ثلاث كروت تفاعلية (اليوم، الشهر، السنة)
- تأثيرات عند الضغط عليها
- كشف التاريخ: 8 سبتمبر 2026
```

#### 3️⃣ العداد التنازلي الحي
```
- عداد يحدث كل ثانية
- يعرض: الأيام، الساعات، الدقائق، الثواني
- يتغير الرسالة عند وصول الموعد
```

#### 4️⃣ خريطة الموقع التفاعلية
```
- ربط مباشر مع Google Maps
- عرض موقع الفندق بضغطة واحدة
- الموقع: فندق جولدن جويل - الإسماعيلية
```

#### 5️⃣ الجدول الزمني
```
07:00 مساءً - استقبال الضيوف الكرام
08:30 مساءً - مراسم عقد القران والزفاف
10:00 مساءً - وجبة العشاء والاحتفال
```

## 🛠️ التقنيات المستخدمة

### Frontend
- **HTML5** - هيكل صفحة الويب
- **CSS3** - التنسيقات والرسوميات والحركات
- **JavaScript (Vanilla)** - البرمجة والتفاعل

### الخطوط والمكتبات
- [Google Fonts](https://fonts.google.com/) - خطوط عربية احترافية
  - Amiri (serif)
  - Reem Kufi (sans-serif)
  - Aref Ruqaa (calligraphy)

## 🎨 التأثيرات والحركات

### Animations المستخدمة
- `fadeIn` - تأثير الظهور التدريجي
- `whiteGlow` - التوهج الأبيض عند فتح المغلف
- `pulse` - تأثير النبض على النص الإرشادي

### Transitions
- تغييرات سلسة في الألوان والأحجام
- تأثيرات عند التمرير (hover effects)
